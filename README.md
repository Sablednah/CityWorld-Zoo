# CityWorld: Zoo

Zoo animals from zombie media, for NeoForge: **giraffe** and **rhesus macaque** (The Last of Us), **zebra**
(The Last of Us Part II), **deer** (The Last of Us, I Am Legend), **lion** (I Am Legend, 12 Monkeys,
Resident Evil Outbreak), **tiger** (The Walking Dead), **elephant** (Resident Evil Outbreak) and a
**brown bear**.

Each is an ordinary animal: a spawn egg, breeding with its food, vanilla behaviour. The carnivores,
the bear and the elephant fight back when hurt; the rest run. And every one comes with a datapack entry
for [CityWorld](https://github.com/Sablednah/CityWorld-ReForged)'s zoos, so a city's zoo fills with them.
CityWorld is optional.

| Minecraft | NeoForge | Java |
|---|---|---|
| 26.2 | 26.2.0.72+ | 25 |

Install on the server **and** every client: these are new creatures, so a client without the mod cannot
join. Commands: `/zoo status` and `/zoo count [radius]` (operators).

`CLAUDE.md` is the working notes; `CHANGELOG.md` the history; `CURSEFORGE.md` the store page.
